# Programación Concurrente

Apuntes y material de estudio personal para la materia **Programación Concurrente** (UNC).

## Estructura del repositorio

- **[Filmimas/](Filmimas)** — Filminas y material teórico de cada clase (PDFs con las diapositivas usadas en cursada).
  - `Clase 1` — Introducción a la programación concurrente, diagramas UML, conceptos básicos de Java.
  - `Clase 2` — Creación de hilos, diagramas UML, lenguajes regulares.
  - `Clase 3` — Práctico de la clase 2, lenguajes regulares (continuación).
  - `Clase 4` — Read/Write Locks, semáforos, `synchronized`/locks, redes de Petri.
  - `Clase 5` — Práctico, `interrupt`/`sleep`/`join`, redes de Petri (casos 1 y 2).
  - `Clase 6` — *(pendiente de cargar)*
  - `Clase 7` — *(pendiente de cargar)*
- **[Libros/](Libros)** — Bibliografía de referencia (concurrencia en Java, sistemas operativos, redes de Petri, programación concurrente).
- **[Apuntes/](Apuntes)** — Resúmenes y notas propias *(a completar)*.
- **[Ejercicios/](Ejercicios)** — Ejercicios para programar en Java, por unidad y con verificador automático (unidades 1 a 5 disponibles).
- **[Trabajos Practicos/](Trabajos%20Practicos)** — Entregas y resoluciones de los TPs de la materia *(a completar)*.
- **[Animaciones/](Animaciones)** — Animaciones o simulaciones (por ejemplo, de redes de Petri o algoritmos concurrentes) *(a completar)*.

## Temas cubiertos

- Hilos: creación, ciclo de vida, `interrupt`, `sleep`, `join`
- Sincronización: `synchronized`, locks, `ReadWriteLock`, semáforos
- Diagramas UML
- Lenguajes regulares
- Redes de Petri
- Conceptos básicos de Java aplicados a concurrencia

## Uso

Este repositorio es de uso personal para organizar el material a medida que avanza la cursada. La estructura de carpetas se irá completando con apuntes propios, ejercicios y trabajos prácticos.
